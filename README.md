# HSA Master - Web App Luyện Thi ĐGNL ĐHQGHN (Tư Duy Định Tính)

Hệ thống web app luyện thi toàn diện phần Tư duy định tính (Ngôn ngữ & Văn học) cho Kỳ thi Đánh giá Năng lực (HSA) Đại học Quốc gia Hà Nội.

## Tech Stack
- Frontend: React + Tailwind CSS + Lucide Icons
- Backend: FastAPI + SQLite + Uvicorn
- Exam Engine: 50 câu / 60 phút theo ma trận chuẩn HSA 2026
